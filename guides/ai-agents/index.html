    AI Agents

    This guide shows how the starter's pieces fit together for AI agents: one sharded actor per agent, a supervised child that keeps the conversation, pipeToSelf for model calls, a per-node rate limiter, a human approval step with ask and a timeout, and snapshots that survive a restart.

    All code on this page is included from the runnable example in example/agent. The example uses a fake model, so it needs no API key and no network:

    ./gradlew :example:agent:bootRun   # runs one demo conversation and logs it
./gradlew :example:agent:test      # the tests named at the end of this page

    Why actors fit agents

    An agent is a long conversation with state, slow external calls, and side effects. Actors give you:

    • One owner per conversation. An agent's actor handles one message at a time, so its history needs no locks, even with thousands of agents on one node.
    • Location transparency. With sharding, the cluster keeps exactly one instance of each agent id and routes messages to it, wherever it lives.
    • No blocked threads. A model call can take seconds. The actor sends the call, keeps answering other messages, and handles the reply as a new message.
    • Supervision. If the agent's code throws, a supervisor restarts it from its last snapshot.

    The model behind an interface

    The agent only knows this interface. The example ships a scripted fake; a real provider is another bean that implements it.

    /**
 * The only thing an agent knows about the model. Swap the fake for a real provider by adding
 * another bean that implements this interface; the agent code does not change.
 */
public interface LlmClient {

    /**
     * Sends the conversation so far and returns the model's next step. Must not block the
     * caller: the agent pipes the result back to itself.
     */
    CompletionStage<LlmReply> complete(List<ChatMessage> conversation);
}

    The fake model used by the example:

    /**
 * A scripted model, so the example runs without an API key or network.
 *
 * <ul>
 *   <li>"weather in &lt;city&gt;" asks for the {@code weather} tool;
 *   <li>"refund &lt;order&gt;" asks for the {@code refund} tool, which needs a human approval;
 *   <li>"my name is &lt;name&gt;" is remembered, and "what is my name?" answers from the conversation;
 *   <li>a tool result is turned into the final answer;
 *   <li>anything else is echoed.
 * </ul>
 */
@Component
public class FakeLlmClient implements LlmClient {

    private final AgentProperties properties;

    public FakeLlmClient(AgentProperties properties) {
        this.properties = properties;
    }

    @Override
    public CompletionStage<LlmReply> complete(List<ChatMessage> conversation) {
        long latencyMillis = properties.getFakeLlmLatency().toMillis();
        return CompletableFuture.supplyAsync(
                () -> reply(conversation), CompletableFuture.delayedExecutor(latencyMillis, TimeUnit.MILLISECONDS));
    }

    static LlmReply reply(List<ChatMessage> conversation) {
        ChatMessage last = conversation.get(conversation.size() - 1);
        if (last.role() == ChatMessage.Role.TOOL_RESULT) {
            return LlmReply.answer("Tool " + last.toolName() + " says: " + last.content());
        }
        String text = last.content().trim();
        String lower = text.toLowerCase(Locale.ROOT);
        int weather = lower.indexOf("weather in ");
        if (weather >= 0) {
            String city = text.substring(weather + "weather in ".length()).replaceAll("[?.!]+$", "");
            return LlmReply.callTool("weather", city);
        }
        if (lower.startsWith("refund ")) {
            return LlmReply.callTool("refund", text.substring("refund ".length()));
        }
        if (lower.startsWith("what is my name")) {
            for (int i = conversation.size() - 1; i >= 0; i--) {
                ChatMessage message = conversation.get(i);
                if (message.role() == ChatMessage.Role.USER
                        && message.content().toLowerCase(Locale.ROOT).startsWith("my name is ")) {
                    return LlmReply.answer(
                            "Your name is " + message.content().substring("my name is ".length()));
                }
            }
            return LlmReply.answer("You did not tell me your name.");
        }
        if (lower.startsWith("my name is ")) {
            return LlmReply.answer("Nice to meet you, " + text.substring("my name is ".length()));
        }
        return LlmReply.answer("You said: " + text);
    }
}

    Tools are beans too. A tool that changes the world asks for a human approval first:

    /** A function the model may ask the agent to run. */
public interface Tool {

    String name();

    /** Tools that change the world wait for a human to approve the call. */
    default boolean requiresApproval() {
        return false;
    }

    String invoke(String argument);
}

    One sharded actor per agent

    Each agent id is a sharded entity. The entity is a thin shell: it spawns the agent logic as a supervised child and forwards every command to it.

    /**
 * One sharded entity per agent id: the cluster keeps exactly one instance of each agent, on
 * some node, and routes every message for that id to it.
 *
 * <p>The entity is a thin shell. It spawns the agent's logic, {@link AgentBrain}, as a child
 * under a restart supervisor and forwards every command to it. If the brain crashes, the
 * supervisor restarts it and it reloads its conversation from the snapshot store.
 */
@Component
public class AgentActor implements SpringShardedActor<AgentActor.Command> {

    public static final EntityTypeKey<Command> TYPE_KEY = EntityTypeKey.create(Command.class, "Agent");

    /** Commands may cross nodes, so they are JSON serializable. */
    public interface Command extends AgentBrain.Message, JsonSerializable {}

    /** A user message. The reply is the agent's final answer for this turn. */
    public static final class Chat extends AskCommand<AgentAnswer> implements Command {
        public final String text;

        @JsonCreator
        public Chat(@JsonProperty("text") String text) {
            this.text = text;
        }
    }

    /** Reads the agent's state. Answered at once, even while an LLM call is pending. */
    public static final class GetConversation extends AskCommand<ConversationView> implements Command {}

    /** Makes the agent throw, to show supervision. */
    public static final class SimulateCrash implements Command {
        @JsonCreator
        public SimulateCrash() {}
    }

    private final AgentBrain.Dependencies dependencies;

    public AgentActor(
            AgentRuntime runtime,
            LlmClient llm,
            ToolRegistry tools,
            AgentSnapshotStore snapshots,
            AgentProperties properties) {
        this.dependencies = new AgentBrain.Dependencies(
                llm,
                tools,
                snapshots,
                runtime.rateLimiter().getUnderlying(),
                runtime.approvals().getUnderlying(),
                properties.getApprovalTimeout(),
                properties.getMaxToolSteps());
    }

    @Override
    public EntityTypeKey<Command> typeKey() {
        return TYPE_KEY;
    }

    @Override
    public SpringShardedActorBehavior<Command> create(SpringShardedActorContext<Command> ctx) {
        String agentId = ctx.getEntityId();
        return SpringShardedActorBehavior.builder(Command.class, ctx)
                .withState(behaviorCtx -> {
                    ActorRef<AgentBrain.Message> brain =
                            behaviorCtx.spawn(AgentBrain.create(agentId, dependencies), "brain");
                    // If the brain stops for good (restart limit hit), the shell stops too and
                    // sharding starts a fresh agent on the next message.
                    behaviorCtx.getUnderlying().watch(brain);
                    return brain;
                })
                .onMessage(Command.class, (brain, command) -> {
                    brain.tell(command);
                    return Behaviors.same();
                })
                .build();
    }
}

    Callers address agents by id and never need to know which node hosts them:

    /** Talks to agents by id. The agent may live on any node of the cluster. */
@Service
public class AgentService {

    private final SpringActorSystem actorSystem;

    public AgentService(SpringActorSystem actorSystem) {
        this.actorSystem = actorSystem;
    }

    public CompletionStage<AgentAnswer> chat(String agentId, String text, Duration timeout) {
        return agent(agentId).ask(new AgentActor.Chat(text)).withTimeout(timeout).execute();
    }

    public CompletionStage<ConversationView> conversation(String agentId, Duration timeout) {
        return agent(agentId)
                .ask(new AgentActor.GetConversation())
                .withTimeout(timeout)
                .execute();
    }

    public void simulateCrash(String agentId) {
        agent(agentId).tell(new AgentActor.SimulateCrash());
    }

    private SpringShardedActorHandle<AgentActor.Command> agent(String agentId) {
        return actorSystem.sharded(AgentActor.class).withId(agentId).get();
    }
}

    Single node by default

    The example sets agent.self-join: true, so one node forms its own cluster. For more nodes, list spring.actor.pekko.cluster.seed-nodes as in the Sharded Actors guide and set agent.self-join: false.

    The agent loop without blocking

    A turn is: user message, rate-limit permit, model call, then either a final answer or a tool call followed by another model call. The model call returns a CompletionStage; pipeToSelf turns its result into a message, so the actor never waits on it.

        private void requestPermit() {
        status = Status.PERMIT;
        deps.rateLimiter().tell(RateLimiterActor.Acquire.replyingTo(permits));
    }

    private Behavior<Message> onPermit(PermitGranted granted) {
        if (status != Status.PERMIT) {
            return Behaviors.same();
        }
        status = Status.LLM;
        ctx.getLog().debug("Agent {} calls the LLM", agentId);
        // The future completes on another thread; pipeToSelf turns it into a message, so
        // the actor never waits and never touches its state from that thread.
        ctx.pipeToSelf(deps.llm().complete(List.copyOf(conversation)), LlmResponded::new);
        return Behaviors.same();
    }

    private Behavior<Message> onLlmResponded(LlmResponded responded) {
        if (status != Status.LLM) {
            return Behaviors.same(); // a reply for an earlier incarnation
        }
        if (responded.error() != null) {
            finishTurn("Sorry, the model call failed: " + responded.error().getMessage());
            return Behaviors.same();
        }
        LlmReply reply = responded.reply();
        if (!reply.isToolCall()) {
            finishTurn(reply.text());
            return Behaviors.same();
        }
        if (++toolSteps > deps.maxToolSteps()) {
            finishTurn("Stopped after " + deps.maxToolSteps() + " tool calls.");
            return Behaviors.same();
        }
        append(ChatMessage.toolCall(reply.toolName(), reply.toolArgument()));
        Optional<Tool> tool = deps.tools().find(reply.toolName());
        if (tool.isEmpty()) {
            toolResult(reply, "unknown tool");
        } else if (tool.get().requiresApproval()) {
            askForApproval(reply);
        } else {
            runTool(tool.get(), reply);
        }
        return Behaviors.same();
    }

    While a call is pending the agent still answers GetConversation at once, and a new Chat waits in a queue until the current turn ends.

    A rate limiter per node

    Model providers limit calls per second. Each node spawns one rate limiter actor and every agent on that node asks it for a permit before each call. It keeps a sliding one-second window, so no one-second span ever holds more than agent.calls-per-second calls.

    /**
 * One per node: hands out permits for LLM calls, at most {@code agent.calls-per-second} in any
 * one-second window. Requests over the limit wait in a queue; a timer wakes the actor when the
 * oldest permit leaves the window.
 *
 * <p>The starter has no rate limiter and no timer wrapper, so this actor uses Pekko's
 * {@code Behaviors.withTimers} and is wrapped with {@link SpringActorBehavior#wrap}.
 */
@Component
public class RateLimiterActor implements SpringActor<RateLimiterActor.Command> {

    public interface Command {}

    /** Ask for one permit. The reply comes when the call may start. */
    public static final class Acquire extends AskCommand<Permit> implements Command {

        /** For actors that want the permit as a message instead of a future. */
        public static Acquire replyingTo(ActorRef<Permit> replyTo) {
            Acquire acquire = new Acquire();
            acquire.withReplyTo(replyTo);
            return acquire;
        }
    }

    /** @param grantedAtNanos {@link System#nanoTime()} when the permit was granted */
    public record Permit(long grantedAtNanos) {}

    private enum WakeUp implements Command {
        INSTANCE
    }

    private static final Duration WINDOW = Duration.ofSeconds(1);

    private final int callsPerSecond;

    public RateLimiterActor(AgentProperties properties) {
        this.callsPerSecond = properties.getCallsPerSecond();
    }

    @Override
    public SpringActorBehavior<Command> create(SpringActorContext actorContext) {
        return SpringActorBehavior.wrap(Behaviors.withTimers(
                timers -> new SlidingWindow(timers, callsPerSecond, WINDOW.toNanos()).behavior()));
    }

    private static final class SlidingWindow {
        private final TimerScheduler<Command> timers;
        private final int limit;
        private final long windowNanos;
        private final Deque<Long> granted = new ArrayDeque<>();
        private final Deque<Acquire> waiting = new ArrayDeque<>();

        SlidingWindow(TimerScheduler<Command> timers, int limit, long windowNanos) {
            this.timers = timers;
            this.limit = limit;
            this.windowNanos = windowNanos;
        }

        Behavior<Command> behavior() {
            return Behaviors.receive(Command.class)
                    .onMessage(Acquire.class, acquire -> {
                        waiting.addLast(acquire);
                        return drain();
                    })
                    .onMessage(WakeUp.class, wakeUp -> drain())
                    .build();
        }

        private Behavior<Command> drain() {
            long now = System.nanoTime();
            while (!granted.isEmpty() && now - granted.peekFirst() >= windowNanos) {
                granted.removeFirst();
            }
            while (!waiting.isEmpty() && granted.size() < limit) {
                granted.addLast(now);
                waiting.removeFirst().reply(new Permit(now));
            }
            if (!waiting.isEmpty()) {
                long untilFree = windowNanos - (now - granted.peekFirst());
                timers.startSingleTimer(WakeUp.INSTANCE, WakeUp.INSTANCE, Duration.ofNanos(untilFree));
            }
            return Behaviors.same();
        }
    }
}

    The node-local actors are spawned once, when Spring starts:

    /**
 * Node-local actors that every agent on this node shares: the LLM rate limiter and the approval
 * gateway. Each node spawns its own, so the rate limit is per node.
 */
@Component
public class AgentRuntime {

    private final SpringActorHandle<RateLimiterActor.Command> rateLimiter;
    private final SpringActorHandle<ApprovalActor.Command> approvals;

    // The actor beans are parameters so Spring registers them before they are spawned here.
    public AgentRuntime(
            SpringActorSystem actorSystem,
            AgentProperties properties,
            RateLimiterActor rateLimiterActor,
            ApprovalActor approvalActor) {
        this.rateLimiter = actorSystem
                .actor(RateLimiterActor.class)
                .withId("llm-rate-limiter")
                .spawnAndWait();
        this.approvals =
                actorSystem.actor(ApprovalActor.class).withId("approvals").spawnAndWait();

        Cluster cluster = actorSystem.getCluster();
        if (properties.isSelfJoin() && cluster != null) {
            cluster.manager().tell(Join.create(cluster.selfMember().address()));
        }
    }

    Per node, not per cluster

    With three nodes the cluster can make three times agent.calls-per-second calls. For a cluster-wide limit, run the limiter as a cluster singleton (asClusterSingleton()) instead.

    A human approval step

    When the model asks for a tool that needs approval, the agent asks the node's approval gateway with a timeout. The gateway holds the request until a human answers; if nobody answers in time, the ask fails and the agent tells the model the tool was not run.

        private void askForApproval(LlmReply call) {
        status = Status.APPROVAL;
        PendingApproval request = new PendingApproval(
                agentId + "-" + UUID.randomUUID(), agentId, call.toolName(), call.toolArgument());
        Duration timeout = deps.approvalTimeout();
        ctx.ask(
                ApprovalDecision.class,
                deps.approvals(),
                timeout,
                replyTo -> new ApprovalActor.RequestApproval(request, timeout, replyTo),
                (decision, error) -> {
                    if (error != null) {
                        return new ApprovalResolved(call, false, "no human answer within " + timeout);
                    }
                    return new ApprovalResolved(
                            call, decision.approved(), decision.approved() ? "approved" : "rejected by a human");
                });
    }

    private Behavior<Message> onApprovalResolved(ApprovalResolved resolved) {
        if (status != Status.APPROVAL) {
            return Behaviors.same();
        }
        LlmReply call = resolved.call();
        Optional<Tool> tool = deps.tools().find(call.toolName());
        if (resolved.approved() && tool.isPresent()) {
            runTool(tool.get(), call);
        } else {
            toolResult(call, "not run: " + resolved.reason());
        }
        return Behaviors.same();
    }

    The human side, for a controller, a chat bot or a test:

    /** The human side of the approval step, for a controller, a Slack bot or a test. */
@Service
public class ApprovalService {

    private static final Duration TIMEOUT = Duration.ofSeconds(3);

    private final AgentRuntime runtime;

    public ApprovalService(AgentRuntime runtime) {
        this.runtime = runtime;
    }

    public CompletionStage<List<PendingApproval>> pending() {
        return runtime.approvals()
                .ask(new ApprovalActor.ListPending())
                .withTimeout(TIMEOUT)
                .execute();
    }

    /** Completes with false if the request is unknown or its timeout has passed. */
    public CompletionStage<Boolean> decide(String requestId, boolean approved) {
        return runtime.approvals()
                .ask(new ApprovalActor.Decide(requestId, approved))
                .withTimeout(TIMEOUT)
                .execute();
    }
}

    Supervision and restarts

    The agent's logic runs under a restart supervisor. Behaviors.setup sits inside Behaviors.supervise, so a restart runs the setup again, and the setup loads the last snapshot:

        /**
     * Restart on failure. {@code Behaviors.setup} sits inside the supervisor, so a restart runs
     * it again and the brain reloads its conversation from the last snapshot.
     */
    public static Behavior<Message> create(String agentId, Dependencies dependencies) {
        return Behaviors.supervise(
                        Behaviors.<Message>setup(ctx -> new AgentBrain(ctx, agentId, dependencies).behavior()))
                .onFailure(SupervisorStrategy.restart().withLimit(10, Duration.ofMinutes(1)));
    }

    private AgentBrain(ActorContext<Message> ctx, String agentId, Dependencies dependencies) {
        this.ctx = ctx;
        this.agentId = agentId;
        this.deps = dependencies;
        this.permits = ctx.messageAdapter(RateLimiterActor.Permit.class, PermitGranted::new);
        dependencies.snapshots().load(agentId).ifPresent(snapshot -> conversation.addAll(snapshot.conversation()));
    }

    Where the supervisor goes

    SpringActorBehavior.builder(...).withSupervisionStrategy(...) puts the supervisor inside its own setup, so a restart keeps the state object made by withState. To reload state on restart, wrap Behaviors.setup in Behaviors.supervise yourself, as above.

    Every change to the conversation is saved before the agent moves on, so a new actor system finds the agent where it left off:

        /** Every change to the conversation is written before the agent moves on. */
    private void append(ChatMessage message) {
        conversation.add(message);
        deps.snapshots().save(new AgentSnapshot(agentId, List.copyOf(conversation)));
    }

    The store is an interface. The example writes one JSON file per agent; for a database, implement it with the ActorSnapshot entity and ActorSnapshotRepository from Persistence with Spring Boot.

    /**
 * Saves and loads agent snapshots. The example writes JSON files; a JPA implementation with an
 * {@code ActorSnapshot} entity and repository, as in example/persistence, plugs in the same way.
 */
public interface AgentSnapshotStore {

    Optional<AgentSnapshot> load(String agentId);

    void save(AgentSnapshot snapshot);
}

    What the starter does not provide yet

    The example builds these itself:

    • Timers. There is no timer wrapper; the rate limiter and the approval gateway use Pekko's Behaviors.withTimers through SpringActorBehavior.wrap.
    • Rate limiting. There is no rate limiter in the starter; the example's is an actor.
    • Supervision of sharded entities. SpringShardedActorBehavior has no supervision or signal option, so the agent puts its logic in a supervised child.
